## Aggiornamento documenti

Quando cambia una funzione:

1. aggiornare il manuale operativo;
2. aggiornare la checklist se cambia un flusso amministrativo;
3. aggiungere o sostituire la schermata corrispondente in `docs/screenshots/`;
4. verificare il comportamento sia in italiano sia in inglese;
5. indicare eventuali limiti tecnici nella sezione `Nota tecnica`.

Questi documenti sono materiali interni e non vengono pubblicati automaticamente.
